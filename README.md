# Фитнес-трекер отжиманий

Android-приложение на Java для лабораторной работы №1 по теме «Работа с сенсорами».

## Что делает приложение

- использует акселерометр;
- считает отжимания по резкому движению/вибрации телефона;
- хранит счетчик, цель и чувствительность в SharedPreferences;
- дает виброотклик после каждого засчитанного повторения;
- показывает уведомление при достижении цели;
- регистрирует слушатель сенсора в onResume/start и снимает регистрацию в onPause/pause.

## Как открыть в Android Studio

1. Распакуйте архив.
2. В Android Studio выберите **File → Open**.
3. Откройте папку `PushUpTracker`.
4. Дождитесь Gradle Sync.
5. Запустите приложение на телефоне или эмуляторе с акселерометром.

## Как тестировать

Положите телефон экраном вверх на пол под грудь. В нижней точке отжимания слегка коснитесь/заденьте телефон. Если счетчик срабатывает слишком часто или редко, измените чувствительность ползунком.
